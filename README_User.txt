TableExtractor (v2025.10.21)
============================

Quick Run:
1. Extract the folder (keep everything together).
2. Open TableExtractor.exe.
3. Open HTML file (or sample) and pick table.
4. Set Channel + Measurement columns.
5. (Optional) Search lists; click items to toggle.
6. Apply (Ctrl+F) / Clear (Ctrl+R) / Export CSV (Ctrl+E).
7. F1 shows shortcuts.

If empty after Apply: press Clear.
Keep all internal files. Version in title.
